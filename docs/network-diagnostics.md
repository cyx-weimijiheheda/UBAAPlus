# 网络诊断与认证恢复

设置按外观、连接与诊断、功能与提醒、桌面小组件、数据与存储、其他选项分组。
「网络诊断」覆盖功能列表的全部 18 项，以及统一认证、更新与公告。

每项分别显示服务 HTTP 响应和主要业务只读查询。登录跳转、HTTP 404 与网络不通分开；
某些根目录不存在，不代表业务接口不可用。未登录跳过学校业务查询；场地独立会话未建立时提示先登录。
每项显示实际连接路线、耗时和固定错误分类，可停止、单项重测、复制或导出脱敏 JSON。

检测最多并发两项，服务响应限时 8 秒、业务查询限时 40 秒。业务检测禁用离线回退和宿舍电表内存缓存。
离开页面、身份或连接代次变化时取消检测，迟到响应不能覆盖新状态。检测不执行预约、选课、签到、支付等业务写入。
报告不包含学校正文、账号、密码、Cookie、会话、票据、余额或原始异常文本。

2026-11-20 在本机 Direct 路线、独立内存账号会话下执行了只读检测：
统一认证及 17 个功能的主要查询成功；SPOC 业务查询未完成；更新与公告 TLS 连接失败。
这是当时本机路线的结果，不代表 Android 真机或校外 WebVPN 结果。没有保存账号响应样本。

主页会话检查失败时，有已保存凭据就立即尝试登录；暂时网络故障按 2、5、15、30、60 秒退避，
后续间隔最多 60 秒，不要求点击底部重试气泡。进入后台暂停，回前台立即继续。
密码错误或验证码挑战停止自动重试并进入登录页；主动退出保持暂停，不会自动重新登录。
模式切换和手动登录取消旧恢复任务，通过代次检查拒绝迟到结果。
