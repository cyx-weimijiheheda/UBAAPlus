## WebVPN 图片验证

对照 `crates/ubaa_core/src/auth/automatic.rs`、`interactive.rs`、`captcha.rs` 和 `captcha_image.rs`：

- 并非取消学校验证码，而是在同一 WebVPN Cookie 作用域中本地识别图片。
- 只处理已支持的 image 类型、六位字母数字；最多自动尝试三次，失败交给原人工输入界面。
- 图像答案、图片 ID 和 execution 必须来自同一个准备页；提交前不重新 GET 登录页。
- POST 参数保持 `username/password/captcha/captchaResponse/execution/_eventId/submit/type`。
- 重试只使用已识别的验证码拒绝响应及其下一张挑战；不把超时或其它错误当作识别失败重提。
- Direct 保持人工输入；会话、Cookie、execution 不跨连接模式使用。取消或切换模式后的旧结果不能恢复界面登录态。

复用 UBAA 随仓库的 `common.onnx.gz` 和 `charset.json`，来源为 ddddocr 1.6.1 的 common_old 模型；后续重新量化 LSTM 以减小模型，详见 [OCR 与首页性能](ocr-and-home-performance.md)。
Android 使用 ONNX Runtime 1.23.2 CPU 推理，五像素白边、170×64 灰度归一化输入、CTC 去重解码。
缩放使用本地双线性采样。模型和字符集不含用户验证码，识别完全在本机完成。识别器兼容 aapt 解压并去掉 `.gz` 后缀的 APK 资源，以及保留 gzip 的资源布局；交付时核对打包后模型与源模型解压字节一致。
模型声明及 MIT 许可证见 [ddddocr-MIT.txt](licenses/ddddocr-MIT.txt)，参考工程许可证见 [UBAA-MIT.txt](licenses/UBAA-MIT.txt)。
ONNX Runtime 的 Java 接口依据：[官方文档](https://onnxruntime.ai/docs/get-started/with-java.html)。

## 显式注销与缓存清理的区别

两个退出选项都先停止抢课、场地自动任务与普通预约，失效旧读取并清除 Direct/WebVPN 会话、Cookie 与令牌；服务器注销失败也完成本地退出。普通「退出登录」保留当前账号的密码、已验证身份、本地化课表和业务缓存，返回登录页，持久暂停自动认证，重启也不会自动登录；用户主动提交登录才解除暂停。

「退出登录并清除本地数据」需要确认，额外删除当前账号的业务缓存、首页/待办快照、成绩缓存、本地化课表（含索引、旧格式与分块）、座位暂离及已提醒记录、个人预约表单和保存的凭据。其他账号课表、缓存与应用外观设置保留；未决学校写入的匿名去重保护不当作普通缓存删除。

设置页「清理缓存」继续保留登录和本地化课表。已保存凭据默认后台尝试登录，不再提供独立自动登录勾选框；优先验证已有会话；认证失败有凭据时立即后台恢复，临时故障按 2/5/15/30/60 秒退避（上限 60 秒），保留会话和缓存，不再显示底部重试气泡。后台暂停、前台立即继续；验证码或密码问题停止重试并引导补全登录。仅凭据、无已验证身份时显示只读首页占位，不读取其他账号的本地数据。

### 博雅简介图片

简介 HTML 只提取文字与图片，不执行脚本或嵌入页面。相对图片地址基于博雅站点解析；站内图片复用当前连接模式的登录 Cookie 和 WebVPN 地址转换，异步读取并检查账户作用域，限制单张 12 MiB。站内图片不写入 Coil 内存或磁盘缓存；外部 HTTPS 图片使用匿名图片加载器，不携带校园登录凭据。失败只影响对应图片，可单独重试。基本信息和课程简介均提供复制图标；复制简介只包含正文文字，图片位置换行，不含图片说明或链接。

## 空教室复测与恢复（2026-11-19）

在独立内存会话中，分别使用直连和 WebVPN 实测三个校区的当天/次日查询与重复刷新。首轮均返回业务码 0，学院路 158 间、沙河 144 间、杭州 68 间，节次均位于 1–14，未发现重复教室 ID 或空 ID；当前接口没有持续性故障，但个别请求有数秒至十余秒延迟。

修正客户端以下边界：

- 空教室子系统同步绑定连接模式、账户和登录代次。遇到明确的 SSO/WebVPN 登录跳转、401 或登录 HTML，使用现有 SSO Cookie 重新同步，最多再读一次；仍失败再核对主会话，不能因子系统失效直接退出仍有效的账户。认证请求隐藏日志中的票据。
- HTTP 200 仍需校验业务码，学校业务错误不再当作成功空结果。PHP 返回的合法空 `list: []` 规范为空映射，非空数组与不完整响应仍拒绝。
- 新查询取消旧查询，并同时检查请求代次、校区与日期。迟到的成功/失败都不能覆盖新选择，取消不会显示查询错误。

回归测试先在修改前复现会话恢复失败、业务错误误报成功、空 PHP 列表解析失败和旧请求覆盖新校区四种问题，随后核对修复结果。页面布局及预约类写操作未改动。

修复后使用相同账号及生产默认超时再次实测：直连/WebVPN × 三校区 × 当天/次日共 12 次查询，再加两条路线各 2 次重复刷新，共 16 次均成功。该结果证明本轮读取正常，不代表所有时间/网络环境都无上游延迟。
